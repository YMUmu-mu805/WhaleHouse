# 更新日志

## 1.0.9 — 2026-10-30

- **修：到饭点只改「正在干嘛」，人没跟着走** —— 会出现「明明在卧室睡觉，却显示在厨房做饭」这种自相矛盾的状态。
  原因是 `tickMeal()` 是个纯状态机，只写 `leisure`（页面上"正在做什么"），不改 `house.current`（真实位置）。
  现在三处触发都会同步把人挪过去：桥接定时器（做饭→厨房、吃饭→餐厅、吃完→休息房间）、两个版本的 `qq_house_meal` 手动 `now`、服务器版的惰性 tick。

## 1.0.8 — 2026-10-30

- **默认房间和家具名全部规范化**：九间屋按更简洁的叫法重命名家具（沙发 / 鱼缸 / 客厅电视 / 茶几 / 冰箱 / 灶台 / 热水壶 / 橱柜 / 浴缸 / 洗手池 / 吊床 / 鸟笼 / 泳池 / 躺椅 / 喷泉 / 花坛 / 书桌 / 台灯 / 笔记本 / 书柜 / 电脑 / 纸箱……），共 9 间房 34 件家具。
- **搬家功能暂停**：只保留一套「小屋」。`qq_house_new` 工具移除，页面副标题不再显示「第 N 个家」，「以前住过的地方」没内容时不显示。后续版本考虑重新加入。
- 页面副标题等文案里去掉「第 N 个家」这类跟搬家绑定的说法。

> 说明：这次只改包里的默认值，**已有的房子数据不受影响**——你原有的家具名、房间名都会保留。

## 1.0.7 — 2026-10-30

- **修：就餐的默认时间显示成 00:00 – 00:00**。原因是存的配置里只有 `enabled`、没有起止时间，界面取不到就回退成 0。现在读配置时自动补默认饭点（7-9 / 11-13 / 17-19），保存时统一存成分钟数。
- 服务器版控制台此前缺少「就餐设置」界面，这次一并补上（饭点、夜宵、不吃饭开关）。

## 1.0.6 — 2026-10-30

- **新增「就餐」功能**：bot 按饭点自动做饭→吃饭→饭后休息。
  - 早餐 7-9 / 午餐 11-13 / 晚餐 17-19（可改，三段不能重合）；夜宵 22 点后、睡觉前，约三成概率想吃，时间不可设。
  - 吃饭时间 = 饭点时段内随机一个点；提前 10~15 分钟去做饭，做好去餐厅吃 20~30 分钟，吃完随机去一个可休息房间（睡觉/游泳/晒太阳/读书）；两次就餐至少间隔 3 小时。
  - 可在高级设置「就餐设置」里改饭点、关掉某一顿、或干脆「不吃饭」。
  - 桥接版按定时器自动触发；服务器版在每次房子工具被调用时惰性推进。新增 `qq_house_meal` 工具（status / now / config）。

## 1.0.5 — 2026-10-30

- **补上「自动截图发送」到服务器版**：之前这两个功能只在桥接版里有，对外发的服务器包没有。现在服务器版也支持——配好 QQ 机器人（OneBot）+ 你的 QQ 号，改格局/移动/被问小屋时会把房子页截图发到你私聊（走 Edge 无头截图 + OneBot `send_private_msg`）。没配通道则静默失效，不影响其它功能。
- 控制台「高级设置」新增「自动截图发送」栏（填 ownerQQ / OneBot 地址 / token + 三个开关）；也可直接改 `qq-shot.json`。

## 1.0.4 — 2026-10-28

- **「设置」按钮挪到房子页标题旁边**（原来只在右下角）：控制台打开的页面里，标题 h1 右边直接有一个「设置」，点开就是小屋格局 / 高级设置两个 tab。静态导出的 HTML 不带这个按钮（点不了接口）。
- 右下角的浮动「设置」按钮保留，两种入口都行。
- **代码合并成一份**：桥接和服务器包共用 `core/` 里的渲染/数据逻辑（环境差异用注入解决），以后改功能只改一处；原有的房子页、数据完全没变（重构前后页面逐字节比对一致、14 个 state 文件零改动）。
- **对外只发一个包**：`WhaleHouse-V1.0.4.zip`（server + plugin + 双击启动 + 示例数据）。
- **「设置」按钮静态页也显示**：直接双击 `exports/` 里的 HTML 也能看到按钮，点了会提示怎么打开控制台（不然点了没反应更让人困惑）。
- **修：服务器版的小游戏页面打不开**（/chess、/snake、/gomoku 全是 404）。原因是控制台启动时只画了房子页和图鉴，棋局/贪吃蛇/五子棋的页面得等有人先玩一局才生成。现在启动时如果还没有，就各开一局并把页面画出来。
- 发版流程加了「重画 bridge 所有页面 + 校验版本水印」两步，避免升级后页面还挂着旧版本号。

## 1.0.3 — 2026-10-28

- **控制台的房子页会自己刷新了**：每 3 秒查一次 /api/page-signature，她在别处走动、开关家电、写日记之后，页面上几秒内就跟着变（不用手动 F5）。面板打开或正在输入时暂停刷新，不打断打字。
- 新增接口 GET /api/page-signature（页面指纹，给前端轮询用）。

## 1.0.2 — 2026-10-28

- **小屋格局新增「家具移动」**：把一个家具从一间屋搬到另一间屋（插件里家具行的「移动」按钮、服务器控制台同步支持），不用再先删后加。
- **bot 用对应家具时会先走到那间屋**：开电视 → 客厅/卧室、开电脑/写日记 → 书房、开冰箱 → 厨房、喂鱼 → 客厅、泡澡 → 卫生间，位置跟着变，更像真的在家里活动。
- **「自动截图发送设置」**（高级设置里，两个开关放在一起）：bot 改格局后自动截图发主人私聊 / bot 移动到别的房间后发当前小屋截图。
- **问小屋状况会自动发图**：主人（或群友）问「小屋现在怎么样」时，bot 回答完会把当前小屋截图发到**提问的那个会话**。

- **日常活动也要去对应房间**：新增 `qq_house_activity` 工具——做饭→厨房、吃饭→餐厅、游泳→庭院、晒太阳→阳台、读书→书房、洗澡→卫生间、睡觉→卧室，都会先走过去；页头会显示「正在…」。
- **白天休息随机、夜里只睡觉**：白天想休息时传 `rest=true` 会随机挑一种（睡觉 / 游泳 / 晒太阳 / 读书），也可以跟主人商量自己定（传 `what` + `room`）；**晚上十点以后到早上六点只能睡觉**（卧室）。

- **状态不再会无声清空**：home-life.json / house.json 读取失败时会先重试、再退回 .bak.json；每次保存前都会留一份备份。

## 1.0.0 — 2026-10-27

首个公开版本。

- **房子**：九间屋（客厅 / 卧室 / 厨房 / 餐厅 / 卫生间 / 阳台 / 庭院 / 书房 / 储物间），
  家具可以添、拿走、挪到别的屋；住腻了能搬家，三种家轮换（普通小屋 / 靠海的小屋 / 顶楼的小房子），
  旧家会收进「以前住过的地方」。
- **平面图**：每间屋一张 SVG 示意图（按家具关键词挑形体），另有一份家具图鉴。
- **家电状态栏**：客厅/卧室两台电视（按时段分开记）、书房电脑（显示上一次玩的游戏的成绩）、
  厨房冰箱（食材）、客厅鱼缸（养的鱼）。
- **国际象棋**：跟电脑下，规则完整（易位 / 吃过路兵 / 升变 / 将死 / 逼和），能认输，记战绩。
- **贪吃蛇**：20×14，吃掉变长、撞墙或撞自己结束，记最高三次分数。
- **五子棋**：15×15，双方准备后开局；特殊技能「天下劫」——下一颗子周围补出至多四颗同色棋子，
  先手第 4 手 / 后手第 3 手起可用，用后等 3 手，一局最多两次。
- **名字可配置**：`config.json` 的 `name` 决定对话称呼、页面标题和文件名。
- **零 DSH 依赖**：标准 MCP stdio 服务，Claude Desktop / Cursor / Cline / Cherry Studio 等都能挂。
- **自检**：`node src/mcp-server.mjs --selftest` 跑一遍主要动作，装机即验证。
