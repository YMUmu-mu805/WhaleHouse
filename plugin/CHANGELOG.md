## 1.0.2 — 2026-10-28

- **小屋格局新增「家具移动」**：把一个家具从一间屋搬到另一间屋（插件里家具行的「移动」按钮、服务器控制台同步支持），不用再先删后加。
- **bot 用对应家具时会先走到那间屋**：开电视 → 客厅/卧室、开电脑/写日记 → 书房、开冰箱 → 厨房、喂鱼 → 客厅、泡澡 → 卫生间，位置跟着变，更像真的在家里活动。
- **「自动截图发送设置」**（高级设置里，两个开关放在一起）：bot 改格局后自动截图发主人私聊 / bot 移动到别的房间后发当前小屋截图。
- **问小屋状况会自动发图**：主人（或群友）问「小屋现在怎么样」时，bot 回答完会把当前小屋截图发到**提问的那个会话**。

- **日常活动也要去对应房间**：新增 `qq_house_activity` 工具——做饭→厨房、吃饭→餐厅、游泳→庭院、晒太阳→阳台、读书→书房、洗澡→卫生间、睡觉→卧室，都会先走过去；页头会显示「正在…」。
- **白天休息随机、夜里只睡觉**：白天想休息时传 `rest=true` 会随机挑一种（睡觉 / 游泳 / 晒太阳 / 读书），也可以跟主人商量自己定（传 `what` + `room`）；**晚上十点以后到早上六点只能睡觉**（卧室）。

- **状态不再会无声清空**：home-life.json / house.json 读取失败时会先重试、再退回 .bak.json；每次保存前都会留一份备份。
